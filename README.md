# Sanal Akademi Kulübü Web Sitesi

Anadolu Üniversitesi Sanal Akademi Kulübü'nün resmî web sitesi projesi.

## Yayınlama

1. Proje kök dizinine `index.html` dosyasını yükleyin.
2. Vercel > Add New > Project üzerinden bu GitHub deposunu içe aktarın.
3. Framework Preset: Other, Root Directory: `./`.
4. Deploy seçeneğiyle yayımlayın.

## Duyurular

İlk HTML sürümündeki duyurular tarayıcıda yerel olarak tutulur. Herkese açık, ortak duyuru yayını ve yönetici yetkilendirmesi için Supabase bağlantısı gereklidir.

## Marka

Kulübün özgün baykuş logosu ve siyah, beyaz, turuncu renk kimliği korunmalıdır.
